# What a Tasmota plug posts to Warblet once a minute: one request body per
# line, as the rule in the setup line builds it (the plug puts one space in
# front). Each reading is the text the power meter gave, in quotes; a reading
# the meter does not have arrives empty.
#
# These were not captured from a plug. They are written from Tasmota 16.0.0's
# source (the rule fills each %value% and %varN% from the meter's ENERGY
# readings), with made-up readings. Nothing else from the plug is ever in a
# post: not the Wi-Fi network's name, not the plug's network name, not an
# address.
#
# A lamp on:
{"Power":"42","Voltage":"121","Current":"0.413","Today":"0.123"}
# The relay off:
{"Power":"0","Voltage":"121","Current":"0.000","Today":"0.123"}
# A heater on:
{"Power":"1450","Voltage":"118","Current":"12.288","Today":"3.456"}
# A meter that does not measure voltage or current:
{"Power":"42","Voltage":"","Current":"","Today":"0.123"}
