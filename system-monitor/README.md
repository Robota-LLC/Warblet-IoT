# System monitor

This Python script sends Warblet how full your computer's disks are, along with its memory in use, load, uptime and, on a Raspberry Pi, the chip's temperature. It is written for Linux, Raspberry Pi OS, macOS and Windows, and needs nothing installed beyond Python. Your device page shows the readings, a routine emails you when a disk is nearly full, and the quiet alert can tell you when the computer stops reporting.
